# Feature-extraction module dependencies.
#
# Verified working together in the conda env `expertasd-features` (Python 3.10)
# on 2026-07-22: SSL + speaker extraction on an A100 (CUDA), plus UMAP plotting,
# all in one process. This is the dependency set the future `worker-features`
# container should build from.
#
# torch/torchaudio are the CUDA 12.6 builds. Install them from the PyTorch index:
#
#   pip install --extra-index-url https://download.pytorch.org/whl/cu126 \
#       torch==2.7.1+cu126 torchaudio==2.7.1+cu126
#   pip install -r features/requirements.txt
#
# (torch is listed below without the +cu126 local version so a plain
# `pip install -r` on a CUDA-12.6 host still resolves; pin the +cu126 build
# explicitly as above for an exact match to what was verified.)

# --- torch runtime (see header for the cu126 index) ---

# --- SSL embeddings ---
